# Math Practice App — Project Brief

## Project Name
math-practice-fe

## Purpose
A TypeScript + React math practice web application designed for children aged 7–10 years old.

## Core Requirements
- Single-digit arithmetic: addition, subtraction, multiplication, division
- 10 questions per round
- Immediate answer verification (correct/incorrect feedback after each answer)
- Score aggregation per round
- Number-only input (on-screen numeric keypad)
- Tablet-compatible UI (touch-friendly, large targets)
- Deployed to GitHub Pages at: https://achilles-mantel.github.io/math-practice-fe/

## Target Users
Children aged 7–10 years old, primarily using tablets.

## Deployment
- GitHub Pages via `gh-pages` npm package
- Repository: git@github.com:achilles-mantel/math-practice-fe.git
- Base URL: `/math-practice-fe/`
